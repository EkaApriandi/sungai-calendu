Panduan Penggunaan

  • Memproses Laporan Warga: Klik tombol "Ubah Status" untuk mengubah laporan dari status Belum Selesai menjadi Selesai.
  • Kirim Pesan WhatsApp: Gunakan tombol "WA" di tabel laporan untuk membalas pesan warga secara otomatis via WhatsApp.
  • Update Pengumuman: Tulis informasi penting di menu Pengumuman Warga. Teks akan langsung muncul di baris teratas halaman utama.
  • Kelola Galeri Foto: Unggah foto kegiatan sungai dan klik tombol "Hapus" jika ada foto yang ingin dihilangkan dari galeri.

Diagnosis Koneksi Google Apps Script

Jika laporan tidak bisa dimuat karena browser diblokir atau error CORS:

  1. Pastikan AdBlocker / Shield browser dinonaktifkan untuk situs ini.
  2. Di Google Apps Script: klik Deploy > Manage Deployments > Edit, atur Who has access ke Anyone.
